# License notes

Split Swap is licensed under the Mozilla Public License 2.0 (`MPL-2.0`). The short identifier is the authoritative license choice; the `LICENSE` file and source-file notices point to the canonical terms.

## What you can do

- Use Split Swap for any purpose.
- Read, modify, and fix the code.
- Share original or modified versions.
- Include it in a larger project.

## What redistribution requires

When someone distributes a modified MPL-covered file, that file must remain available as source code under MPL-2.0. Copyright and license notices must be preserved. MPL's copyleft applies at the file level rather than forcing an unrelated larger work to use MPL.

## Why there is no “no paywall” clause

The Open Source Definition requires free redistribution and does not allow a license to forbid commercial use or sale. Adding a no-sale or no-paywall restriction would make Split Swap source-available, not open source, and could conflict with an open-source-only mod-store policy.

MPL still prevents a distributor from turning modified covered files into closed source. Anyone who lawfully receives a copy retains the right to redistribute the covered source, including at no charge. Official releases maintained by [jasi](https://github.com/001vamp) are intended to remain freely available.

This document explains the maintainer's intent and is not an additional license restriction.
